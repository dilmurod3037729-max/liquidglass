# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work and not the person. Harassment of any kind is not accepted.
Report problems privately to the maintainer through GitHub (**Security → Report a vulnerability** works for this too, or contact
[@dilmurod3037729-max](https://github.com/dilmurod3037729-max)). Maintainers may remove comments, issues or contributors that break these rules.
